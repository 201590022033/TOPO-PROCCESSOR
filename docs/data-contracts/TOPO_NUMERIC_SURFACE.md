# Current Topography Numeric Surface Contract Status

M5 is an evidence-gated no-go for surface export. The current application can expose scalar result parameters through the M2 adapter, but it cannot honestly populate `CorneaData.anteriorSurface`.

The active TypeScript `elevationMap` is an internal Float32Array generated by a bounded heuristic formula and rendered to `corneal_surface_3d.png`. Its “mm” comment is not calibration evidence. `powerMap` drives axial/tangential display maps but is not a verified physical curvature grid. Neither is persisted or exported as a numeric surface.

The regular-grid contract therefore remains unavailable with reason `unsupported-by-source`. Pixel centre coordinates remain `px`, not `mm`; outer NaN pixels do not become a validity mask. RGB heatmaps, K1/K2, eccentricity, and ring count cannot substitute for a physical anterior surface.

The retained legacy Python arc-step/Zernike code is research evidence only: it contains experimental XYZ/elevation-like intermediates but is not the current route and lacks a verified calibration fixture. It is not promoted by M5.
