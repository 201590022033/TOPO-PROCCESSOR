The retained Python prototype names sensor dimensions, focal length, target model file, working distance, and gap functions, but the corresponding evidence files are absent and the path is not active. Its reconstruction code is therefore classified C: structurally informative reference material, unsuitable as a production basis until independently recovered and validated.

Camera strategy: first obtain manufacturer/device specifications (A); if unavailable, directly measure camera/target geometry (B) without disturbing alignment; use a standard calibration target only if compatible with the optical setup (C); jointly solve effective parameters against a known calibration sphere only after A–C evidence exists (D).
