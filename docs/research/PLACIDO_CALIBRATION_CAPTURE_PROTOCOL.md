# Calibration Capture Protocol

Use the original source image whenever possible, not a screenshot. Do not crop, resize, filter, or otherwise transform the image before archiving it. Preserve EXIF and instrument metadata. Retain failed captures when they reveal alignment or detection limits.

Capture at least 5 repeated acquisitions of the same calibration object without changing instrument settings. Record the working-distance setting, original image dimensions, acquisition time when useful, object orientation, focus, alignment quality, illumination state, and any operator notes. This supports engineering repeatability only; repetition does not establish clinical accuracy.
