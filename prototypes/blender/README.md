# Blender Prototype Placeholder

Blender is reserved for validating geometry, surfaces, clinical overlays, registration landmarks, and interaction. It must not become a dependency of the clinical engine or the normalized data contracts.

Blender v7 experimentally validated a renderer concept. Production geometry now originates from the shared geometry engine; a future Blender adapter will consume its output. Blender must not become clinical truth. The validated v7 script should later be copied into this directory by the architecture/integration workstream. No Blender prototype has been recreated or integrated in this milestone.
