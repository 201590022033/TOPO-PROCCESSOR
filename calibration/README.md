# Placido Calibration Evidence Package

This directory is an evidence-package placeholder for the physical instrument. It intentionally contains no claimed instrument measurements, camera intrinsics, target dimensions, or calibration-eye specification. Unknown values are recorded explicitly; do not treat this package as a calibration.

- `instrument-profile.json` — instrument identification, currently unknown.
- `target-geometry.json` — physical target geometry, currently unknown.
- `camera-evidence.json` — camera evidence, currently unknown.
- `calibration-object.json` — project-owner calibration eye, currently unknown.
- `acquisitions/` — reserved for original, unmodified captures and observation metadata.

Validate a completed package with the `evidencePackageSchema` in `shared/clinical/placido/calibration-evidence.ts`.
